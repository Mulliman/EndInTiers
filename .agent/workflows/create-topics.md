---
description: How to create and integrate multiple high-quality ranking topics at a time.
---

Follow these steps when tasked with creating new topics for the EndInTiers database.

### 1. Identify Context and Placement
- Determine what the prompter wants to create topics for.
- Locate the correct **Category** (e.g., Food, Music, Movies). If a correct category doesn't exist, create it.

### 2. Think of and create the topics

- Based on what is being prompted try to create up to 10 fun topics that would allow players to have a fun time guessing how their friends word order certain things.
- These things can be items, concepts, groups, interests / hobbies, places, pieces of culture, anything really that can be ordered.
- Determine the appropriate **Sub-category** folder for each. If a correct sub-category doesn't exist, create it.
- Use the existing /create-topic workflow to create the topics for each idea.
- Check that the categories/sub categeories/topics/questions/options that have been created are accurate and fun.
